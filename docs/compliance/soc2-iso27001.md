# SOC 2 / ISO 27001 readiness map

Implemented controls include least-privilege workspace roles, audit events, API key revocation, signed webhooks, privacy policy controls, retention enforcement, deletion requests, security headers, dependency auditing, secret scanning, migration review, and CI gates.

Evidence still requiring organizational execution: vendor reviews, employee access reviews, formal risk register, policy approvals, incident exercises, backup/restore evidence from the production provider, penetration test report, and independent audit/certification.
