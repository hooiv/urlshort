# Links nearing their click limit

`GET /api/links/near-cap?workspaceId=&limit=50&threshold=80` lists active links with a `maxClicks` cap that have used at least `threshold` percent of it (integer 1–99, default 80) but are not yet over it, closest to the cap first. Each row has `clicks`, `maxClicks`, `percentUsed` (floored) and `remaining`; `total` is the full match count. `limit` is 1–200. Session auth or an API key with `analytics:read` / `links:read`; workspace viewers only see links they may read. The comparison uses integer arithmetic in SQL, so 8/10 matches an 80% threshold exactly. UI: `/manage/near-cap`, which sets a new limit, removes the limit, or archives selected links through `PATCH /api/bulk/edit` (audited). Links already at the cap belong to `/manage/expired`.
